# دار إيلاف — عالم إيلاف للأزياء

عالم مستقل بالكامل. تدخلين له من زر «دار إيلاف» بشاشة الدخول، أو بخريطة الغابة، أو من «دار إيلاف» بخريطة «عالمنا»، أو من الرابط `index.html#fashion`.

إيلاف نفسها ما تتغير: الدمية مبنية من أجزاء صورتها الأصلية (الراس، الشعر، اليدين، الرجلين) مقصوصة بـ clip-path، والملابس الجديدة مرسومة SVG فوقها وتتحرك ويا المفاصل (نفس نظام `stories/tales-rig.js`).

## شلون الملابس مربوطة بالجسم

| القطعة | الطبقة | تتحرك ويا |
|---|---|---|
| الورك والفخذين للبنطلون | `fz-hip` | ثابتة ويا الجسم |
| ساق البنطلون + الجوارب + الحذاء | `fz-leg` (لكل رجل) | الرجل، تنثني من الركبة |
| التنورة وتنورة الفستان | `skirt` | تتمايل وتنفرد ويا المشي والقفز |
| القطعة العلوية والأوفرول والشنط | `fz-core` | الجسم |
| الأكمام، الساعة، شنطة اليد | `fz-sl` (لكل إيد) | الذراع |
| القبعات والطوق والمشابك | `fz-acc` | الراس |
| الأجنحة، شنطة الظهر، قبعة الهودي | `fz-back` | ورا الجسم دايماً |

حدود ساقي إيلاف (`LO/LI/RI/RO` بـ `fashion-art.js`) مقاسة من بكسلات صورتها، فكل بنطلون يغطي الساق بالضبط مهما تغيّرت القصّة أو الطول.

## الملفات

| الملف | شنو بيه |
|---|---|
| `fashion-art.js` | الكتالوج (ألوان، نقشات، أقمشة، أجنحة، إكسسوارات) ورسم الملابس والأجنحة والدمية، وأصدقاء الدار ومعالم الخريطة |
| `fashion-core.js` | الحفظ، المكافآت والخزانة، المدخل، خريطة الدار، الأصدقاء، الخيوط الذهبية، إطار الألعاب، حفظ التصاميم، تصوير اللقطات |
| `fashion-design.js` | مشغل إيلاف، ورشة الأجنحة، غرفة القياس، متحف الإطلالات |
| `fashion-games.js` | الألعاب الـ15، ألغاز قاعة الأقمشة الثلاثة، قاعة الأقمشة، غرفة الأسرار |
| `fashion-show.js` | الكواليس وتجهيز العرض، مسرح العرض الكبير، استوديو الصور، ساحة المهرجان والمواسم العشرة |
| `fashion.css` | أسلوب الدار |

## الحفظ

- التقدّم والتصاميم بـ `localStorage` تحت المفتاح `gh_fashion`.
- الصور بـ IndexedDB (`fashion-media`).
- ماكو تسجيل دخول ولا إرسال بيانات.

## المكافآت

| النشاط | المكافأة |
|---|---|
| ألغاز قاعة الأقمشة | قماش جديد لكل مستوى |
| الألعاب | لون أو نقشة لكل مستوى (مرة وحدة بس) |
| استكشاف الكواليس | خلفية مسرح |
| حفظ تصاميم بالمتحف | إكسسوارات |
| عرض كامل | حركة عرض جديدة |
| الخيوط الذهبية المخفية | جناح خاص لكل مكان، وبعد الأربعة تنفتح غرفة الأسرار |
| تحدي كل موسم | قماش أو جناح أو نقشة خاصة |

## الإضافة

- **قماش:** سطر بـ `FABRICS` و`case` بـ `fabricDefs` داخل `fashion-art.js`.
- **نقشة:** سطر بـ `PATTERNS` و`case` بـ `patternDef`.
- **جناح:** سطر بـ `WINGS` وشكل بـ `WSH` (جزء فوق `t` وجزء جوّا `b`). التصاميم الجاهزة بـ `WPRESETS`.
- **قطعة ملابس:** علوية بـ `TOPS` + رسمها بـ `topWear`، سفلية بـ `BOTTOMS` + `pantsHip`/`pantsShin` أو `skirt`، حذاء بـ `SHOES` + `shoe`.
- **لعبة:** `FW.game("id", {title, how, art, rw:[ثلاث مكافآت], run(ctx)})` وبعدين أضيفي الـ id لـ `gameShelf` بالمنطقة. داخل `run` تنادين `ctx.win(رسالة، نجوم)` أو `ctx.fail(رسالة، الحل)`.
- **موسم:** سطر بـ `SEASONS` داخل `fashion-show.js` بيه الاسم والألوان والتحدي والمكافأة.
