# حكاياتنا — عالم القصص

عالم مستقل داخل الموقع. تدخلين له من زر «حكاياتنا» بشاشة الدخول أو بالخريطة، أو من الرابط `index.html#tales`.

## الملفات

| الملف | شنو بيه |
|---|---|
| `stories/season1.js` | **نصوص الحكايات كلها**: الحكايات الخمس، الفصول الخمسة عشر، الحوار، الألغاز، الاختيارات، والبيئات |
| `stories/tales-engine.js` | المحرّك: المكتبة، فتح الكتب، المشهد، الحركة، الحوار، الحفظ، والإعدادات |
| `stories/tales-puzzles.js` | أنواع الألغاز (16 نوع) |
| `stories/tales-audio.js` | الموسيقى الأصلية المولّدة، والمؤثرات، والأغاني اللي تضيفونها |
| `stories/tales-art.js` | رسوم SVG للبيئات والأشياء |
| `stories/tales-rig.js` | حركة أيلاف وعدول: أجزاء مقصوصة من صورتهم الأصلية (راس، شعر، يدين، رجلين، فستان) تتحرك كل وحدة حول مفصلها |
| `stories/tales.css` | ألوان وأسلوب عالم القصص |
| `assets/ADOOL_OFFICIAL_CHARACTER.png` | شخصية عدول (الملف الأصلي) |
| `assets/JAMOUS_CUSTOM_FOREST_MASCOT.png` | شخصية جعموص (الملف الأصلي) |

صورة أيلاف هي نفسها الموجودة بـ `index.html` (`GIRL`)، وسومو (رفيق الغابة) هو رسمته الأصلية `ART.sumo`.

## تعديل نص

افتحي `stories/season1.js` وابحثي عن الجملة وغيّريها. داخل النصوص تنكتب الأسماء كرموز:
`{E}` أيلاف، `{A}` عدول، `{J}` جعموص، `{S}` سومو، و`{SR}` لقب سومو. الأسماء نفسها تنقرا من `CONFIG` بـ `index.html`.

## إضافة فصل جديد

أضيفي عنصر جديد لمصفوفة `chapters` بأي حكاية:

```js
{
  id:"s1c4", title:"عنوان الفصل", teaser:"سطر قصير يظهر بالمكتبة",
  cliff:"جملة نهاية الفصل",
  scenes:{ room:{ theme:"treeIn", len:160, gk:"wood" } },
  beats:[
    {scene:"room", cast:{elaf:[16], adool:[10]}, player:"elaf"},
    {say:"adool", t:"هلا {E}!", e:"wave"},
    {explore:{until:"door"}},
    {puzzle:"quiz", title:"سؤال", q:"…", opts:["…","…"], a:0}
  ]
}
```

الفصل ينفتح تلقائياً بعد الفصل اللي قبله. أنواع الخطوات كلها مشروحة أعلى `season1.js`.

## الصوت

- كل حكاية إلها موسيقى أصلية تتولّد بالمتصفح بثلاث حالات: مقدمة، استكشاف، ولحظة عاطفية.
- **إضافة أغنية تملكون حقها:** من المكتبة اضغطي زر الإعدادات، وبعدها «أغانيكم الخاصة». اختاري الملف والحكاية والفصل والمقطع. الملف ينحفظ على هذا الجهاز فقط.
- أو حطّوا الملف بالمشروع واربطوه بـ `audio` بآخر `season1.js`، مثل: `s1:{intro:"assets/audio/s1-intro.mp3"}`.
- الصوت ما يشتغل قبل ما تضغطين على شي.

## الحفظ

التقدّم والاختيارات والصفحات المكتوبة تنحفظ على الجهاز فقط (`localStorage` بمفتاح `gh_tales`، والأغاني بـ IndexedDB). ماكو تسجيل دخول ولا إرسال بيانات.
