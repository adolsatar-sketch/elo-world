# عالمنا — عالم إيلاف وعدول

عالم تفاعلي بخريطة رئيسية و12 منطقة. تدخلين له من زر «عالمنا» بشاشة الدخول أو بخريطة الغابة، أو من الرابط `index.html#world`.

## الملفات

| الملف | شنو بيه |
|---|---|
| `world-core.js` | النواة: الحفظ، المقتنيات، المناطق وشروط فتحها، الخريطة، المهام اليومية، الأوسمة، أصدقاء العالم، الشخصيتين بالمشاهد، وإطار الألعاب المشترك |
| `world-art.js` | الرسوم: المقتنيات، الحيوانات، معالم الخريطة، الأثاث، النباتات |
| `world.css` | أسلوب العالم وكل منطقة |
| `world-home.js` | البيت فوق الشجرة: 6 غرف، ترتيب الأثاث بالسحب، الجو |
| `world-forest.js` | غابة الاستكشاف: 8 أماكن على محرّك الحكايات |
| `world-garden.js` | الحديقة: زراعة، سقي، قطف، تسمية، زينة، نبتة اليوم |
| `world-museum.js` | متحف الذكريات + المرسم (معرض الرسومات) |
| `world-kitchen.js` | مطبخ الغابة: 6 وصفات |
| `world-sky.js` | مرصد القمر: كوكبات، أمنيات، رسائل النجوم |
| `world-river.js` | نهر الألعاب: 7 ألعاب مائية |
| `world-arcade.js` | ساحة الألعاب: 12 لعبة |
| `world-festival.js` | جزيرة المهرجانات: 10 مهرجانات |
| `world-beach.js` | شاطئ الغيوم: 7 أنشطة |
| `world-post.js` | محطة البريد والرسائل |

## الحفظ

كل شي محفوظ على الجهاز فقط:
- **التقدّم:** المقتنيات، الحديقة، البيت، الرسائل، والأوسمة تنحفظ بـ `localStorage` تحت مفتاح `gh_world`.
- **الصور والرسومات:** تنحفظ بـ IndexedDB (`world-media`).

ماكو تسجيل دخول ولا إرسال بيانات.

## إضافة منطقة جديدة

1. أضيفي سطر لـ `REG` داخل `world-core.js`، بيه الاسم ومكانها بالخريطة (`x` و`y` نسبة مئوية)، وشرط الفتح `need` إذا تحتاجينه.
2. أضيفي رسمة معلم بـ `WART.land` داخل `world-art.js`.
3. سوّي ملف `world-<id>.js` بيه:

```js
World.region("id", (body, {first}) => {
  body.appendChild(h(`<div class="wr">…</div>`));
  return () => { /* تنظيف عند الخروج */ };
});
```

4. أضيفي الملف لـ `index.html` جنب باقي ملفات `world`.

## إضافة لعبة

ضيفي عنصر جديد لـ `WArcade.G` (بـ `world-arcade.js`) أو لـ `WRiver.GAMES` (بـ `world-river.js`)، بيه `title` و`how` و`levels` و`run(ctx)`.

داخل `run`، كل شي يتحرك لازم يمر على `ctx.fit(x, y, w, h)` حتى يبقى داخل الإطار. وبالنهاية تنادين `ctx.win(رسالة, مكافأة, نجوم)`.
